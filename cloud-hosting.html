Cloud hosting runs your site on a network of servers, so it can handle more visitors and grow with you. It suits busy sites, web apps and projects that need more control.

What to look for

  • Managed cloud hosting is easier if you are not technical.
  • Check which server locations are available near your visitors.
  • Understand how billing works, hourly or monthly.
  • Make sure backups and monitoring are included.
